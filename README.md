# SwiftOrganize 
A modern, high-speed desktop utility built with Python to instantly declutter your folders.

SwiftOrganize is a sleek, Dark-Mode enabled desktop application designed to solve the "messy Downloads folder" problem. With one click, it scans your directory and sorts files into logical categories.

---

##  Key Features
-  One-Click Sorting:** Instantly move hundreds of files into organized subfolders.
-  Smart Logic:** Categorizes files by extension (Images, Docs, Videos, Code, etc.).
-  Misc Fallback:** Automatically moves unrecognized files (like .webp or .iso) into a `Misc_Other` folder so nothing is left behind.
-  Modern UI:** Built with `CustomTkinter` for a native, high-end feel with a real-time progress bar.
-  Safety First:** Automatically ignores system folders and hidden files to prevent accidental moves.
